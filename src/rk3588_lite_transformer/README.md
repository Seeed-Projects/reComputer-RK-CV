# RK3588 Lite Transformer Deployment Guide

[English] | [中文](./README_zh.md)

English-to-Chinese translation demo accelerated by the RK3588 NPU. The Web UI shows the translation and the exact BPE token IDs consumed and generated by the model.

## Features

- English text input and Chinese text output
- Browser UI, REST API, and one-shot CLI
- Explicit 15-source-token validation instead of silent truncation
- Docker one-command deployment

## Directory Structure

- `model/`: encoder, decoder, tokenizer dictionaries, and embeddings
- `task_runtime.py`: preprocessing, RKNN inference, and decoding
- `web_service.py`: FastAPI service and Web UI
- `inference.py`: command-line inference
- `web/`: English browser interface

## Quick Start

```bash
sudo docker run --rm --privileged --net=host \
    -e PYTHONUNBUFFERED=1 -e RKNN_LOG_LEVEL=0 \
    -v /proc/device-tree/compatible:/proc/device-tree/compatible:ro \
    ghcr.io/seeed-projects/recomputer-rk-cv/rk3588-lite_transformer:latest
```

Open `http://<Board_IP>:8000`. No camera, display, or audio device mapping is required.

### Command Line

```bash
python inference.py --platform rk3588 --model_dir model --text "thank you"
```

## API

```bash
curl -X POST http://127.0.0.1:8000/api/models/lite_transformer/predict \
    -F 'text=thank you'
curl http://127.0.0.1:8000/api/health
```

The response includes `translation`, `input_tokens`, `output_tokens`, and token counts. Interactive OpenAPI documentation is available at `/docs`.

## Input Constraints

- Source language: English; target language: Chinese.
- The fixed encoder accepts at most 15 BPE tokens plus EOS. A word can produce multiple BPE tokens.
- This compact example model is intended for short phrases; translation quality is not comparable to a large general-purpose translation model.
